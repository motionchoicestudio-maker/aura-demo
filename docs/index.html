AURA Dental

WordPress block theme for dental and aesthetic clinics · Version 1.0.0

1. Installation

  1. In WordPress go to Appearance → Themes → Add New → Upload Theme, choose aura-dental.zip, install and activate.
  2. Go to Plugins → Add New → Upload Plugin, choose aura-dental-core.zip (in the package's plugins/ folder), install and activate. The plugin adds Services, Doctors, Specialties, the booking form and the demo importer. The theme works without it, but the service and doctor sections will be empty.
  3. Appearance → Import AURA demo → Import demo content. This creates the pages (Home, Clinic, Contact, Your First Visit, Journal), six services, twelve doctors, four articles and sets the front page. It is safe to run twice.
  4. Settings → Permalinks → Save Changes once, so /services/ and /doctors/ URLs work.

3. Custom fields

Fields are registered as post meta and show up in the block editor. Open the post, then either edit a bound block inline (the paragraph shows the field value) or use the Custom Fields panel (Options ⋯ → Preferences → Panels → Custom Fields).

Post typeFields (meta key)
Serviceaura_tagline, aura_price, aura_price_label (e.g. $1,900), aura_price_note (per implant), aura_duration, aura_visits, aura_quote, aura_quote_author, aura_doctors (doctor post IDs, comma separated)
Doctoraura_badge, aura_credentials, aura_years, aura_years_label, aura_quote, aura_education, aura_since, aura_q1/aura_a1 … aura_q3/aura_a3

4. Booking form

Shortcode [aura_booking_form] (attributes: title, light="1" for the white version). Requests are emailed to the site admin address. To send elsewhere add to a small plugin or your child theme:

add_filter( 'aura_dental_booking_recipient', function () { return 'reception@example.com'; } );

Prefer Contact Form 7 or WPForms? Put their shortcode in place of [aura_booking_form] inside the Booking pattern.

5. Colors, fonts, spacing

  • All colors, font sizes and spacing are in Appearance → Editor → Styles (theme.json). Change "Blue" and "Blue Glow" to re-brand the whole site.
  • Font: Satoshi, loaded from Fontshare. Swap it with add_filter( 'aura_dental_font_url', fn() => 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;700&display=swap' ); and change the font family in Styles → Typography.
  • Logo: Appearance → Editor → Site logo (34×34 works best). Without a logo the theme shows its own mark.
  • Menus: Appearance → Editor → Navigation. The header menu collapses into an overlay below 600px.

6. Animations

Scroll reveals, counters, the reviews slider and the services scroll-spy are powered by GSAP (bundled). They respect prefers-reduced-motion. To disable them completely, dequeue the script:

add_action( 'wp_enqueue_scripts', function () { wp_dequeue_script( 'aura-dental' ); }, 20 );

7. Child theme

The package includes aura-dental-child.zip. Install it the same way as the theme (Appearance → Themes → Add New → Upload Theme) and activate it instead of AURA Dental. Put your CSS in its style.css and PHP snippets (such as the filters above) in its functions.php; parent theme updates will not overwrite them. The Site Editor changes you make while the child theme is active are stored for the child theme.
